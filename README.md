# NgbeatsApp

Technical test project built with Angular. It is a CRUD application that allows users to view, add, edit, and delete songs.

The application has a simple, responsive UI and is designed to demonstrate core Angular concepts such as components, forms, routing, and state management.

## Technologies Used

- **Angular 19**: Frontend framework used for building the application.
- **TypeScript**: Programming language used to develop the app.
- **Lucide Icons**: Set of SVG icons used in the UI.
- **CSS**: To style the application.

## Installation

1. Clone this repository

```
bash git clone <repo-url>
```

2. Install dependencies

```
bash npm install
```

3. Run development server

```
bash ng serve -o
```
